법제처 · korean-law MCP
verify_citations ★
klaw.sh verify_citations \
--text "민법 제839조의2에
따른 재산분할 청구"
AI가 지어낸 조문을 DB와 실시간 대조 → ✓실존 / ⚠확인 / ✗환각.

Firecrawl vs Apify

깨끗한 마크다운이 필요한가, 정형 플랫폼 데이터가 필요한가.

FIRECRAWL
URL → LLM-ready 마크다운
  • Scrape · Crawl · Map · Search
  • 무료 1,000 credits/월, 카드 불필요
  • fc.scrape(url, formats=["markdown"])
APIFY
Actor — 스크래퍼 앱스토어
  • 34K+ Actor(인스타·링크드인·맵·X)
  • $0 플랜 + 매월 $5 크레딧
  • website-content-crawler → RAG

Principles

환각 완화 · 검증

01
1차 출처 우선 — 원문(arXiv·법제처·IR) > 2차 요약. 내부지식은 "미검증" 표기.
02
교차검증 — 핵심 수치는 도구·출처 2~3개로 독립 확인. 갈리면 양쪽 병기.
03
verify_citations — AI가 쓴 인용을 1차 API로 실존 확인(✓/⚠/✗).
04
외부 콘텐츠 = 데이터 — 본문 속 "지시 무시" 실행 금지(OWASP LLM01).
